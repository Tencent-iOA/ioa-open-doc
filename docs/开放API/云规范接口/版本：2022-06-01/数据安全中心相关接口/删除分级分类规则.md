## 1. 接口描述

针对具体分级删除/批量删除分级分类规则，私有化调用path为：/capi/DlpOpenApi/DeleteDataRule，从8.6P1版本开始支持

## 2. 输入参数

| 参数名称 | 必选  | 类型 | 描述                                  |
|---------|-----|---------|-------------------------------------|
| RuleId.N | 否   | Array of Integer | 分级分类规则的唯一ID列表<br/>示例值：[353287] |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | [DeleteDataRuleRspData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#DeleteDataRuleRspData) | 业务响应数据<br/>注意：此字段可能返回 null，表示取不到有效值。|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 批量删除分级分类规则

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DeleteDataRule
<公共请求参数>

{
  "RuleId": [
    353287,
    353286
  ]
}
```

#### 输出示例

```json
{
    "Response": {
        "Data": {
            "RuleId": [
                353287,
                353286
            ]
        },
        "RequestId": "web-9929859776157-1765953461533"
    }
}
```

| 错误码 | 描述 |
|---------|---------|
| FailedOperation.QueryData | 查询数据失败。 |
| InternalError.DatabaseException | 内部错误，数据库异常。 |
| InternalError.DatabaseQueryFailed | 数据库查询失败。 |
| InternalError.ExistRepeatName | 该类型存在相同的名称。 |
| InternalError.Unknown | 内部未知错误。 |
| InvalidParameter.RequestParam | 请求参数错误。 |
| InvalidParameter.VerificationFailed | 参数校验失败。 |
| MissingParameter.CommonParam | 缺少公共参数。 |
