## 1. 接口描述

在指定规则分类下添加分级分类规则，私有化调用path为：/capi/DlpOpenApi/CreateDataRule，从8.6P1版本开始支持

## 2. 输入参数

| 参数名称 | 必选  | 类型 | 描述                                  |
|---------|-----|---------|-------------------------------------|
| Name | 是   | String | 分级分类规则名称;Required:true<br/>示例值：身份证图片 |
| Description | 否   | String | 分级分类规则描述<br/>示例值：检测包含身份证号码的图片 |
| OsType | 否   | Integer | 系统类型（0: win，1：linux，2: mac，3: win_srv，4：android，5：ios，默认值0）<br/>示例值：0 |
| CategoryId | 是   | Integer | 规则分类Id;Required:true（只支持64位）<br/>示例值：26320 |
| DataLevel | 是   | String | 数据级别;Required:true<br/>示例值：S3 |
| Status | 否   | Integer | 开关状态（0:停用 1:启用）<br/>示例值：1 |
| RuleUsage | 否   | String | 规则用途 |
| Expression | 否   | String | 表达式内容<br/>示例值：doc.Size > 1048576 |
| IsCustomize | 否   | Integer | 是否用户自定义（0:内置 1:自定义）<br/>示例值：1 |
| LibraryId.N | 否   | Array of Integer | 所选词库唯一Id列表 |
| ConditionContent | 否   | String | 条件内容 JSON 字符串 |
| FileSourceId.N | 否   | Array of Integer | 文件来源Id列表 |
| ExprFileSource | 否   | String | 文件来源表达式内容 |
| UseDocPath | 否   | Integer | 文件路径匹配（0:关闭 1:开启）<br/>示例值：0 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | [CreateDataRuleRspData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#CreateDataRuleRspData) | 业务响应数据<br/>注意：此字段可能返回 null，表示取不到有效值。|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: CreateDataRule
<公共请求参数>

{
  "Name": "超管-自测-2",
  "Description": "测试分级分类规则",
  "OsType": 0,
  "CategoryId": 26315,
  "DataLevel": "S4",
  "Status": 1,
  "IsCustomize": 1,
  "Expression": "doc.Size > 1048576",
  "ConditionContent": "{\"Id\":\"g0\",\"Conditions\":[],\"Groups\":[{\"Conditions\":[{\"Values\":[\"1048576\"],\"Option\":\">\",\"ValueType\":\"float\",\"FieldKey\":\"doc.Size\",\"Id\":\"g0/g1/1\"}],\"Groups\":[],\"GroupType\":\"FileSize\",\"Id\":\"g0/g1\",\"RelateOption\":\"and\"}],\"GroupType\":\"Root\",\"ValidCount\":0}",
  "LibraryId": [],
  "FileSourceId": [],
  "ExprFileSource": "",
  "UseDocPath": 0
}
```
