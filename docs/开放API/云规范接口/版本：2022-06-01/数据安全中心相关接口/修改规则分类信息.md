## 1. 接口描述

针对一条规则分类修改分类名等，私有化调用path为：/capi/DlpOpenApi/ModifyDataCategory，从8.6P1版本开始支持

## 2. 输入参数

| 参数名称 | 必选  | 类型 | 描述                                  |
|---------|-----|---------|-------------------------------------|
| CategoryId | 是   | Integer | 规则分类列表的唯一ID（只支持64位）<br/>示例值：26315 |
| Name | 是   | String | 规则分类名称;Required:true<br/>示例值：产品设计资料 |
| Description | 否   | String | 规则分类描述<br/>示例值：用于产品设计相关的资料分类 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | [ModifyDataCategoryRspData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#ModifyDataCategoryRspData) | 业务响应数据<br/>注意：此字段可能返回 null，表示取不到有效值。|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 修改规则分类

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ModifyDataCategory
<公共请求参数>

{
  "CategoryId": 26315,
  "Name": "产品设计资料",
  "Description": "更新后的规则分类描述"
}
```

#### 输出示例

```json
{
    "Response": {
        "Data": {
            "CategoryId": 26315
        },
        "RequestId": "web-1245921911577-1765938455417"
    }
}
```
