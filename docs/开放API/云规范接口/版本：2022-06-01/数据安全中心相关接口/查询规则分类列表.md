## 1. 接口描述

查询规则分类列表及其包含的分级分类规则条目，私有化调用path为：/capi/DlpOpenApi/DescribeDataCategory，从8.6P1版本开始支持

## 2. 输入参数

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Condition | 否 | [Condition](/开放API/云规范接口/版本：2022-06-01/数据结构.md#Condition) | <strong><font color="blue"></font></strong>过滤条件<br> <li>Id - int - 是否必填：否 - 操作符: eq  - 排序支持：否- 按照规则分类Id进行过滤。</li> <li>Name - String - 是否必填：否 - 操作符: eq  - 排序支持：否- 按照规则分类名进行过滤。</li> <li>IsCustomize - int - 是否必填：否 - 操作符: eq  - 排序支持：是- 按照自定义类型（0:内置 1:自定义）进行过滤。</li> 分页参数<br> <li>PageNum 从1开始，小于等于0时使用默认参数1。</li> <li>PageSize 最大值5000，最好不超过100。</li> |
| OsType | 否 | Integer | 系统类型（0: win，1：linux，2: mac，3: win_srv，4：android，5：ios，默认值0）<br/>示例值：0 |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | Array of [DescribeDataCategoryRspData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#DescribeDataCategoryRspData) | 业务响应数据<br/>注意：此字段可能返回 null，表示取不到有效值。|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 查询规则分类列表

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeDataCategory
<公共请求参数>

{
  "Condition": {
    "Filters": [
      {
        "Field": "IsCustomize",
        "Operator": "eq",
        "Values": [
          "1"
        ]
      }
    ],
    "Sort": {
      "Field": "Utime",
      "Order": "desc"
    },
    "PageSize": 10,
    "PageNum": 1
  },
  "OsType": 0
}
```
