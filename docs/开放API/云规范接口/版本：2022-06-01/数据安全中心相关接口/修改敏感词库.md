## 1. 接口描述

针对一条敏感词库修改词组具体内容，私有化调用path为：/capi/DlpOpenApi/ModifyDataLibrary，从8.6P1版本开始支持

## 2. 输入参数

| 参数名称 | 必选  | 类型 | 描述                                  |
|---------|-----|---------|-------------------------------------|
| LibraryId | 是   | Integer | 敏感词库的唯一ID;Required:true（只支持64位）<br/>示例值：5209 |
| Name | 是   | String | 敏感词库名称;Required:true<br/>示例值：身份证号 |
| Description | 否   | String | 敏感词库描述<br/>示例值：更新后的敏感词库描述 |
| Label.N | 否   | Array of String | 标签列表 |
| Status | 否   | Integer | 开关状态（0:停用 1:启用）<br/>示例值：1 |
| Content | 否   | String | 词组内容 |
| HitCount | 否   | Integer | 命中次数<br/>示例值：1 |
| TotalWeight | 否   | Integer | 总权重<br/>示例值：1 |
| OsType | 否   | Integer | 系统类型（0: win，1：linux，2: mac，3: win_srv，4：android，5：ios，默认值0）<br/>示例值：0 |
| IsCustomize | 否   | Integer | 是否用户自定义（0:内置 1:自定义）<br/>示例值：1 |
| Type | 否   | String | 词组类型（regex 正则/kw 关键字/dict 字典）<br/>示例值：regex |
| Internal | 否   | Integer | 内置表达式（0:否 1:是）<br/>示例值：0 |
| Repeat | 否   | Boolean | 权重是否可重复（true:可重复 false:不可重复）<br/>示例值：false |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | [ModifyDataLibraryRspData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#ModifyDataLibraryRspData) | 业务响应数据<br/>注意：此字段可能返回 null，表示取不到有效值。|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 修改敏感词库

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: ModifyDataLibrary
<公共请求参数>

{
  "LibraryId": 5209,
  "Name": "身份证号",
  "Description": "更新后的敏感词库描述",
  "Label": ["个人信息"],
  "Status": 1,
  "Content": "[1-9]\\d{5}(18|19|20)\\d{2}(0[1-9]|1[0-2])(0[1-9]|[12]\\d|3[01])\\d{3}[\\dXx]",
  "HitCount": 1,
  "TotalWeight": 1,
  "OsType": 0,
  "IsCustomize": 1,
  "Type": "regex",
  "Internal": 0,
  "Repeat": false
}
```

#### 输出示例

```json
{
    "Response": {
        "Data": {
            "LibraryId": 5209
        },
        "RequestId": "web-3461177967511-1765938455559"
    }
}
```


## 5. 错误码

| 错误码 | 描述 |
|---------|---------|
| FailedOperation.QueryData | 查询数据失败。 |
| InternalError.DatabaseException | 内部错误，数据库异常。 |
| InternalError.DatabaseQueryFailed | 数据库查询失败。 |
| InternalError.ExistRepeatName | 该类型存在相同的名称。 |
| InternalError.Unknown | 内部未知错误。 |
| InvalidParameter.InvalidRegexp | 无效的正则表达式。 |
| InvalidParameter.RegexpInnerTimeOut | 正则表达式执行内部超时。 |
| InvalidParameter.RequestParam | 请求参数错误。 |
| InvalidParameter.VerificationFailed | 参数校验失败。 |
| MissingParameter.CommonParam | 缺少公共参数。 |
| ResourceNotFound.NotFound | 资源不存在。 |
| UnauthorizedOperation.PermissionDenied | 未授权的操作。 |
