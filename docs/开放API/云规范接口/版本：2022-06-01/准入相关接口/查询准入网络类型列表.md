## 1. 接口描述

查询准入网络类型列表，私有化调用path为：capi/inac/DescribeINacNetTypes, 从8.7P6版本开始支持

## 2. 输入参数

| 参数名称 | 必选 | 类型 | 描述 |
|---------|---------|---------|---------|
| Condition | 否 | [Condition](/开放API/云规范接口/版本：2022-06-01/数据结构.md#Condition) | <p>条件过滤</p> |

## 3. 输出参数

| 参数名称 | 类型 | 描述 |
|---------|---------|---------|
| Data | [INacNetTypesPageData](/开放API/云规范接口/版本：2022-06-01/数据结构.md#INacNetTypesPageData) | <p>网络类型分页数据</p>|
| RequestId | String | 唯一请求 ID，由服务端生成，每次请求都会返回（若请求因其他原因未能抵达服务端，则该次请求不会获得 RequestId）。定位问题时需要提供该次请求的 RequestId。|

## 4. 示例

### 示例1 查询所有网络类型

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeINacNetTypes
<公共请求参数>

{}
```

#### 输出示例

```json
{
    "Response": {
        "RequestId": "built-in-1786412448",
        "Data": {
            "Page": {
                "PageCount": 0,
                "PageSize": 1000,
                "PageNum": 1,
                "Total": 2
            },
            "Items": [
                {
                    "NetworkType": "办公网",
                    "Id": 2
                },
                {
                    "NetworkType": "开发网",
                    "Id": 1
                }
            ]
        }
    }
}
```

### 示例2 指定条件查询

#### 输入示例

```
POST / HTTP/1.1
Host: ioa.tencentcloudapi.com
Content-Type: application/json
X-TC-Action: DescribeINacNetTypes
<公共请求参数>

{
  "Condition": {
    "PageNum": 1,
    "PageSize": 10,
    "Filters": [
      {
        "Field": "NetworkType",
        "Values": [
          "发"
        ],
        "Operator": "like"
      }
    ]
  }
}
```

#### 输出示例

```json
{
    "Response": {
        "RequestId": "built-in-1786412552",
        "Data": {
            "Page": {
                "PageCount": 0,
                "PageSize": 10,
                "PageNum": 1,
                "Total": 1
            },
            "Items": [
                {
                    "NetworkType": "开发网",
                    "Id": 1
                }
            ]
        }
    }
}
```
